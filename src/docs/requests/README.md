# Запросы потребителей к TrueMoon

В общей рабочей области используйте правила и каталог модуля в
`.local/requests/` основного checkout. Найдите этот checkout по подтверждённой
карте окружения. Если очередь недоступна, согласуйте передачу с владельцем модуля.

В публичной задаче опишите версию пакета, ограничение API, ожидаемое поведение
и минимальное воспроизведение на синтетических данных. В публичном diff, коммите
или PR используйте сведения, пригодные для публикации. Исходные реквесты
потребителей, служебные пути, материалы приёмки и данные о владельцах задач
хранятся в локальной очереди. Ссылку на публичный PR добавляют в локальную карточку.

Владелец модуля отвечает за разбор, реализацию и технические проверки в
соответствующем PLAN. Потребитель проверяет полученную версию пакетов в своём
приложении. Общий порядок планирования описан в [PLANNING](../PLANNING.md).
