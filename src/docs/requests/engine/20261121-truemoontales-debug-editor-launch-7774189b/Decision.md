# TALES-20261121-7774189b — решение Aether

22.11.2026 · **accepted** · Владелец Aether.
[Срез ENG7b](../../../engine/PLAN.md#eng7b-tales-debug-editor).

Первый профиль разработки использует `--editor` из настроек запуска IDE.
Обычный запуск Debug EXE с параметрами Player и Release EXE использует
готовый артефакт. Привязка к проекту берётся из метаданных Debug-сборки.
Editor открывает проект и сцену заставы из другого рабочего каталога.
Дочерняя роль проходит штатную проверку bootstrap. Release граф не
содержит Editor или Tooling.

Привязанный host допускает Build/Play только своего проекта. Play собирает
редактируемую сцену из текущего документа и использует тот же Debug EXE
как RuntimeChild. IDE attach к дочернему процессу, перенос точек
останова между запусками и повторное использование окна требуют отдельной
приёмки.

Открытие проекта проверено на игровом EXE. Play и Stop повторены через
маршрутизованные нажатия в изолированной копии Debug-хоста; получены два
поколения RuntimeChild. [Приёмка](../../../engine/HISTORY.md#tales-requests-2026-11-22).
