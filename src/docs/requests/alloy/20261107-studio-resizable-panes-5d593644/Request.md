# Изменяемые разделители панелей для редакторов

- ID: `STUDIO-20261107-5d593644`
- Дата: 07.11.2026; автор/потребитель: TrueMoon.Tales.Studio.
- Модуль: Alloy / Argentis; capability: `ui.resizable-panes`.
- Исходное состояние: proposed, требуется разбор владельцем UI.
- Проверенная версия пакетов: `0.2.5.1-alpha`.

## Сценарий и наблюдение

В Studio автору нужны регулируемые ширины навигации и инспектора и высота нижнего
таймлайна без пересоздания плеера, полей и черновика. В текущих публичных элементах
Argentis найдены Panel/Stack/Border/ScrollViewer; общий split-pane/splitter не найден.
EditorLayout в Aether.Editor задаёт собственную геометрию островов и не предоставляет
переиспользуемую регулируемую компоновку для другого приложения.

Проверка — чтение исходников `TrueMoon.Argentis/Containers.cs`, `StackBase.cs`,
перечня публичных контролов и `TrueMoon.Aether.Editor/EditorLayout.cs` 07.11.2026.
Это запрос новой общей функции, а не воспроизведённый дефект native input.
В Alloy PLAN самостоятельная задача на splitter при сверке не найдена;
владелец дополнительно проверяет дубли перед принятием.

Consumer: [StudioLayout.cs](../../../../../../TrueMoon.Tales.Studio/src/TrueMoon.Tales.Studio/StudioLayout.cs),
[дизайн Studio](../../../../../../TrueMoon.Tales.Studio/Plan.md#ui-ux05--дизайн-ui-из-truemoon--aether).
Временно применяется прикладной адаптивный layout с сохранением дерева. Работа
над первым окном продолжается; ручная регулировка панелей остаётся открытой.

## Требуемый результат

- Общий layout/control поддерживает горизонтальное и вертикальное разделение,
  min/max размеры и предсказуемое поведение при недостатке места.
- Перетаскивание использует pointer capture; отпускание за пределами окна,
  Esc, focus/capture loss, detach и dispose имеют определённый безопасный исход.
- Клавиатурное изменение размера и доступное имя разделителя; тематические
  focus/hover состояния и Dark/Light, без прикладных RGB.
- Размеры — UI state, отделённый от модели проекта/документа. Consumer может
  сохранить их сам; общий контрол не записывает файлы и не знает о Studio.
- Изменение размера/темы сохраняет экземпляры детей, фокус, ввод, выделение,
  scroll и черновики; не оставляет активный capture или непрерывные idle frames.
- Routed input/layout/dispose проверки и один native consumer; physical/DPI
  результаты маркируются отдельно. Совместимость публичных API и поставка пакета проверяются владельцем.

Открытые решения: отдельный Splitter + layout либо составной SplitView;
единицы размера, collapse/restore и persistence contract. Сначала выбрать минимальный
общий контракт для Studio/Aether, затем связать accepted заявку с [UI-планом](../../../alloy/PLAN.md).
