# Продолжение consumer Studio: компоновка и меню

07.11.2026. Дополнение к `STUDIO-20261107-5d593644`, capability `ui.resizable-panes`.

В Studio реализованы прикладная компоновка с полноразмерными боковыми панелями,
центральным монтажом и закреплёнными действиями инспектора, скрытие/восстановление
панелей и режим просмотра. Используются существующие MenuBar/OverlayHost и header
фабрика: для меню расширение API TrueMoon не потребовалось.

Разделители всё ещё нужны как общий контрол: временная компоновка адаптируется
к 1280×820 / 880×640, но не предоставляет drag изменения ширины/высоты.
Проверочный consumer сохраняет дерево, текущий кадр и черновик при смене режима.
При будущей интеграции splitter учитывать открытое popup, capture/focus и fixed
нижние действия инспектора; изменения layout не должны записывать Studio.project.json.

Свидетельства и повтор: [WindowMenus](../../../../../../../TrueMoon.Tales.Studio/src/WindowMenus.md),
[StudioLayout](../../../../../../../TrueMoon.Tales.Studio/src/TrueMoon.Tales.Studio/StudioLayout.cs).
Заявка остаётся предложением для владельца Alloy; приоритет/ownership исходного
запроса этим дополнением не изменены.
