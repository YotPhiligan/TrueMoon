# TrueMoon.Nom: состояние и точка продолжения

**2026-11-21 — NOM6.1 поставлен в main.** Коммит `27129fe` включает пять
исходников `TrueMoon.Nom/Backup`, адресное исключение в `.gitignore` и версию
`1.2611.21.8-alpha`. Из чистой копии этого дерева прошли сборка и по
874 теста Nom и 1 522 Editor в Debug и Release.
Прошли по 16 групп backup/restore в Debug и published Release, а также
13 профилей четырёх независимых потребителей по NOM7.
[Проверки](HISTORY.md#nom6-1-verification-2026-11-21).

**2026-11-20 — внешний PNG через TrueMoon.Aether.Nom.** Мост публикует
base-color текстуру с постоянным ID и точной ревизией. Старый снимок
сохраняет исходный ключ после реимпорта PNG. Оба снимка проверены через
Build и Vulkan в трёх профилях.
[Приёмка ARCH1f.5](../engine/HISTORY.md#arch1f5-imported-png-2026-11-20).

**2026-11-18 — ARCH1g.2h проверил захват нескольких снимков в одну сборку.**
Мост TrueMoon.Aether.Nom использует существующие exact snapshot и read-stream API.
Перестановка и повтор эквивалентных снимков сохраняют BuildId, конфликт ревизий
одного AssetId отклоняется. Снимки удалось удалить после успешного и неудачного
захвата, а сохранённые сборки открылись на GPU в четырёх профилях Player.
В Debug и Release Nom 874/874.
[Проверки ARCH1g.2h](../engine/HISTORY.md#arch1g2h-2026-11-18),
[предыдущий прогон удаления и GC](../engine/HISTORY.md#arch1g2g-2026-11-18).
Решение об отсрочке VM acceptance сохраняется.
