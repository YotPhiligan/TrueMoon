# Aether / Editor: состояние и точка продолжения

**2026-11-19 — ARCH1g.2m.** Сохранённый выбор импортов,
версия **1.2611.19.4-alpha**. Editor восстанавливает точные выбранные поколения
по идентификатору сцены. После отмены и повторного открытия сохраняется прежний
выбор, после успешного реимпорта восстанавливается новое поколение. Конфликт
записи и повреждённый checkpoint сохраняют активный документ. Из восстановленного
выбора собирается новый артефакт с геометрией изменённой модели.
Шесть профилей Editor на Cobalt и Microsoft DI, включая свежие пакеты.
