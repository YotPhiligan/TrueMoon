# Aether / Editor: состояние и точка продолжения

**2026-11-19 — ARCH1g.2k.** Реализован и проверен,
версия **1.2611.19.2-alpha**. Правка и удаление красного BIN меняют статус
только красной модели. Build останавливается до компиляции и сохраняет
предыдущего кандидата. Выбор поколения реимпорта возвращает обе модели в
актуальное состояние, следующая сборка содержит обновлённые ресурсы.
Проверено в шести профилях нативного Editor с Cobalt и Microsoft DI, включая
независимый Release на свежих пакетах. Aether Editor — 1507/1507 в Debug и
Release. Выбор задаёт код authoring-композиции для текущего открытия документа.
[Контракт](MODEL_BUILD_DELIVERY.md#arch1g2k-editor-model-imports),
[проверки](HISTORY.md#arch1g2k-2026-11-19).

**2026-11-18 — ARCH1g.2i.** Проверка актуальности импорта перед сборкой.

[Контракт](MODEL_BUILD_DELIVERY.md#arch1g2i-import-freshness),

на свежих пакетах. Aether Importing 144/144 в Debug и Release.
