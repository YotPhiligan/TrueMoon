# Aether / Editor: состояние и точка продолжения

22.11.2026 — локальная поставка `1.2611.22.1-alpha` для TrueMoon.Tales.
Standalone Player показывает [HUD заставы](PLAN.md#eng5c4-tales-outpost-hud);
resize и Stop проверены Vulkan-кадрами и счётчиками ресурсов. Debug EXE
открывает [привязанные проект и сцену](PLAN.md#eng7b-tales-debug-editor) из
другого рабочего каталога, Release сохранил Player-only граф. После отказа
на сцене без игровых сущностей повторный запуск Release прошёл.
Открыты горячая смена сцены/сборки в standalone Player и проверка перехода
между мониторами с разным DPI. [Приёмка](HISTORY.md#tales-requests-2026-11-22).

21.11.2026 — [ARCH1f.7](PLAN.md#arch1f7-orthographic-camera). В локальной
поставке `1.2611.21.10-alpha` пакетный Player показал изометрический
маршрут TrueMoon.Tales из готового Build. Vulkan подтвердил сохранение
масштаба четырёх ориентиров при 1200×810 → 1560×810, новую surface
generation и штатное освобождение ресурсов. По 702 render/ECS теста
прошли в Debug и Release. [Приёмка](HISTORY.md#arch1f7-tales-route-2026-11-21).

21.11.2026 — первый [оконный срез TrueMoon.Tales](PLAN.md#eng7b4-tales-consumer)
проверен на пакетах `1.2611.21.9-alpha`. В отдельном окне видны изменения от
игрового ввода. Шесть профилей Player подтвердили native lifecycle и точный
пакетный граф. В самой игре проверены загрузка World, Win32-ввод и закрытие.
[Приёмка](HISTORY.md#eng7b4-tales-consumer-2026-11-21).

**Ревизия 2026-11-21.** Из чистой копии дерева `1.2611.21.8-alpha`
прошли сборка и по 1 522 теста Editor в Debug и Release. Это дерево
с исходниками Nom Backup поставлено в `main` коммитом `27129fe`.
[Проверки NOM6.1](../nom/HISTORY.md#nom6-1-verification-2026-11-21).

В `1.2611.21.9-alpha` проверены видимость и слои MeshRenderer. Два Apply
дают отдельные записи Undo/Redo. Новый процесс Editor восстанавливает
флаг и маску из сцены. Vulkan различает совпадающие и несовпадающие маски
камеры и меша. [Приёмка](HISTORY.md#ed4i-mesh-visibility-2026-11-21).

Проекция камеры ED4i проверена в `1.2611.20.5-alpha`.
На `1.2611.20.2-alpha` переимпорт выбранной модели, Build и подтверждение
Replace работают из интерфейса Editor во время Playing. После отказа
устаревшего Build и публикации кандидата исходный Runtime показал тот
же кадр. После Replace он сменился новым Runtime с той же логической
текстурой, новой ревизией и продолжением тика.
[Контракт и приёмка](PLAN.md#arch1f5-editor-playing-texture-workflow).

## Следующий конкретный шаг

Для TrueMoon.Tales — провести персонажа Kton через ступени и скосы и
проверить открытие обзора при входе. [Требования игры](PLAN.md#arch1f7-orthographic-camera).

Оставшиеся задачи инспектора — поведение при смене ресурсов, Play и нативном
Edit Preview. [Очередь ED4i](EDITOR_PLAN.md#ed4i-next).
Причина исторического drain timeout, device loss, физический input/DPI,
платформенная и release-матрица остаются открыты.

Проверки этого статуса относятся к датам соответствующих запусков.
[Предыдущие сводки и команды](HISTORY.md#engine-status-before-review-2026-11-20).
