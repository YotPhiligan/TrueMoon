# Generated audio fixture

`music.ogg` is the self-generated 12-second stereo Ogg Vorbis research melody,
44.1 kHz, created by `ManualTests/MiniAudioExResearch/Fixtures.cs` with
OggVorbisEncoder 1.2.2. No third-party recording is used. Tests copy it to temporary
Unicode paths and derive truncated/CRC/header failure fixtures. Its SHA is recorded
in each acceptance manifest. The encoder is not a production Audio dependency.
