# Работа с TrueMoon

Общий C# пакетный фреймворк. [README](README.md),
[общая карта](../README.md), [правила рабочей области](../AGENTS.md).

- Для любых задач внутри src сначала читать [src/AGENTS.md](src/AGENTS.md): там
  действуют подробные правила namespace, модульных планов, App/DI/lifetime и UI.
  Этот корневой файл дополняет навигацию; существующие инструкции src сохраняются.
- Общие источники технического состояния: [PLAN](src/docs/PLAN.md),
  [STATUS](src/docs/STATUS.md), [PLANNING](src/docs/PLANNING.md), затем документы модуля.
- Проверять Git до правки; сохранять незакоммиченные файлы и локальный src/.codex.
  Исторические passing-результаты не выдавать за новую сборку/тестирование.
- Приложения используют пакеты TrueMoon. Конкретные правила игры/мира принадлежат
  TrueMoon.Tales и Lore; общие технические контракты развиваются во фреймворке.
- Изменения публичных API/пакетов, зависимостей и native/GPU путей проверять в
  соответствующем модуле. Работы по разделению репозиториев не означают рефакторинг C#.
- После работы обновлять относящиеся к задаче планы/статусы по правилам src.
