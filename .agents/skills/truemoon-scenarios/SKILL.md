# Сценарные проверки TrueMoon

Прочитай [сценарный запуск Player](../../../src/docs/engine/SCENARIO_TESTING.md) для формата, синтетического примера с двумя кубами и кодов выхода.

- Выбери точную пакетную поставку. Для воспроизведения используй пакетную фикстуру из руководства. Если проверяешь своё приложение, подготовь Build для точной идентичности выбранного PlayerProbe.dll с тем же набором пакетов.
- Для каждого запуска выбери новый каталог. Проверь отчёт после выхода процесса. Сопоставь запрошенные и фактические тики, доступные наблюдения, размер и поколение поверхности.
- Сравнивай PNG между прогонами после сверки Build ID, хешей сценария и сцены, версии пакетов, backend и масштаба.
- При сбое прочитай код выхода, отчёт и диагностику. Укажи последний завершённый шаг и итог освобождения окна, поверхности, слотов и дескрипторов.
- Описывай результат в пределах проверенных ожиданий. Подтверждение игрового состояния требует наблюдения из игрового адаптера. Приведи ссылки на отчёт и кадры.
